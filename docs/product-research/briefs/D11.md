# D11 — custom-code modules: planning brief

Date: 2026-11-07. Status: **planning only, for Kosta's approval. No product code, no launch implied.**
Base: origin/master 354b0358 (D09 composites, D10 panels merged; `.kabl`-only format). Source: `docs/PRODUCT-PLAN.md` D11, D12 for context.

## 1. Outcome and out-of-scope

Outcome: prove, with a runnable prototype and reproducible numbers, that a distributed, sandboxed code module can run on the real engine as a normal `Module`, survive its own faults, and carry D10 panel metadata. End state is a recommended backend pinned to tested versions, or a documented feasibility failure.

Out of scope: the creator SDK, template, packaging and validation (D12); a store, accounts, payments; real-time file/network access; compilation on the audio thread; a native-plugin loader (never shipped); several source languages at once; GUI authoring tools; Faust as a promised runtime; GPU; threads inside modules; claims of unrestricted real-time code.

## 2. What the code gives us (measured from source)

- `kabl_modules::Module` (`crates/modules/src/module.rs:124`): `info`, `prepare(sr, max_block, quality)`, `process(&mut ProcessIo)`, `reset`, `save_state/load_state` (`StateBuf`: 12 f32 entries, 16-byte keys), `carry_from(&old)` for large state across graph swaps, `view`, `as_any`. Its doc already says "one interface for built-in, composite and code modules".
- `ProcessIo`: inputs/params are `Signal::{Scalar,Buffer}` (control-rate tier), outputs are `&mut [f32]`, indices follow `ModuleInfo.ports/params` order; width-2 ports take two slots.
- `ModuleInfo` is all `&'static` (kind, ports, params, explain, skin). `registry::create(kind)` returns `Box<dyn Module>` from a static table (`compile.rs:1697`). **Code modules need owned or leaked metadata and a dynamic registry path.** That is the real work of PR 1.
- Voices: `Rate::Voice` modules are instantiated once per voice lane in the compiler; `Rate::Global` is shared. A graph swap builds a new `CompiledGraph`, runs `save_state/load_state/carry_from` on the audio thread, then crossfades. A nonfinite guard already exists at `compile.rs:2287`.
- D09/D10: composites own members plus `ports`/`controls` exposures (`Exposure{label,target}`); `Panel` = placements keyed by exposure id (`Knob|Selector|Jack`), light/dark PNG ≤128 KiB; `Panel::validate(&Composite)`. A code module is a leaf, so its metadata must yield the same exposure/panel shape to reuse the D10 UI unchanged.

## 3. Module ABI sketch (v1, `abi=1`)

One `.wasm` core module, no WASI, no imports except an optional `kabl.log`. Host-driven; all memory is host-allocated at prepare.

| Export | When | Rules |
|---|---|---|
| `kabl_abi() -> i32` | load | must equal host ABI major, else reject (not trap) |
| `kabl_meta() -> ptr,len` | load (control thread) | CBOR/JSON: kind, version, name, help, rate (voice/global), ports `{name,type,width}`, params `{name,min,max,default,unit,taper,smoothing_ms}`, `advanced`, optional D10 `panel` |
| `kabl_prepare(sr, max_block, tier)` | control thread | may allocate inside its own memory; declares pages and state size |
| `kabl_reset()` | audio, between notes/swap | zero state; no alloc |
| `kabl_process(n)` | audio | reads/writes fixed io regions in linear memory (host copies in/out) |
| `kabl_state_size()`, `kabl_save(ptr)`, `kabl_load(ptr,len,ver)` | control/swap | opaque bytes; version passed so a module may migrate; replaces the 12-float `StateBuf` for code modules |

- Ports/params are fixed at load from `kabl_meta`, same `PortType` set and width rule as built-ins. Params arrive per block as scalar or buffer (host flags which). Smoothing stays host-side.
- Voices: one **instance per voice lane** (own store and memory, no shared mutable state); global modules get one. Voice stealing calls `reset`. Max instances declared in meta; the host refuses a graph over the cap.
- Versioning: ABI major (host-owned); module `kind` + `version` (author-owned, stored in the patch like `Definition{id,version}`). Unknown version → silent bypass plus an actionable "missing module X v3" report; never a crash.
- Limits: max memory pages (module `maximum` = initial, no `memory.grow` after prepare), max fuel per block, max instances, no table growth.

## 4. Runtime candidates and real-time safety

Common: validate, compile and instantiate on the control thread; the audio thread only receives a ready instance through a graph swap (same path as `Box<dyn Module>` today). No allocation or compilation in `process`, asserted with a counting allocator. On any fault the instance is **marked dead for the block, outputs zeroed, a lock-free fault flag raised to the UI**, and stays bypassed until `reset` or reload.

| Candidate | Budget | Trap handling | Notes |
|---|---|---|---|
| **wasmtime** (Cranelift at load) | fuel (metered) or epoch interruption (cheaper, wall-clock, needs a ticker thread) | `Result` from `call`; instance reusable (spike: yes) | Fastest. Biggest tree; JIT needs executable memory; recent releases need newer rustc than local 1.93. |
| **wasmi** (interpreter) | fuel | `Result`, reusable | Pure Rust, small, no JIT; slower (spike: 1.5x wasmtime on a tiny kernel). Fallback for hardened hosts. |
| **Native reference** (Rust, same shape, in the test binary) | none | `catch_unwind` as test oracle only | Cost baseline. **Never shipped as a loader.** |
| **Faust** | n/a | n/a | Authoring only: `faust -lang wasm` output wrapped to the ABI for one example. A failed wrap does not affect the runtime choice. |

Fuel counts instructions, not time, so it is not real-time proof by itself. The measurement plan checks wall-clock per block against the callback budget, with epoch as a second guard if fuel is too coarse.

## 5. Spike (throwaway, not merged)

One-pole lowpass over a 128-sample block, state in linear memory, 200k calls, release build, this machine. Crates resolved to the newest versions compatible with local rustc 1.93: wasmtime 45.0.3, wasmi 2.0.0 (wasmtime 50 needs rustc 1.97).

| | per 128-sample block |
|---|---|
| native Rust | 351 ns |
| wasmtime, fuel on, including host copy in and out | 599 ns (about 1.7x) |
| wasmtime empty call (n=0) | 17 ns fixed overhead |
| wasmi, fuel on, copy in only | 903 ns |

Faults: an infinite loop with 1e7 fuel traps after 2.3 ms on wasmtime and 11.1 ms on wasmi; both stores run again after refuelling. Instantiate: wasmtime 6.3 us, wasmi 2.0 us (182-byte module). At 48 kHz/128 samples one wasmtime instance is about 0.02 % of a core. **Caveats:** one tiny kernel; 1e7 fuel already exceeds the 2.67 ms block budget on wasmi, so per-block fuel must be sized (about 1e6), not generous. Real numbers need the PR 2 module set. Source is in the job tmp dir, not in the repo.

## 6. Measurement plan and pass thresholds

Harness: feature-gated bench binary, offline render, fixed seed, 48 kHz, blocks 64/128/512, median of 5 runs. Callback budget = block/sr (2.67 ms at 128).

| Test | Pass |
|---|---|
| Per-instance CPU, stateful filter | wasmtime ≤ 3x native and ≤ 0.1 % core; wasmi ≤ 10x native (decides its fallback role) |
| Fixed per-call overhead (n=0) | ≤ 1 us |
| N instances: 1, 8, 32, 128 | linear within 20 %; 128 instances ≤ 25 % of block budget |
| Polyphony: 16 voices × 3 code modules, held chord, 5 min | no xruns in the render probe; p99.9 block time ≤ 50 % budget; zero audio-thread allocations |
| Graph swap (add/remove/replace, state carried) | swap-block p99.9 ≤ 75 % budget; state restored bit-exact; no click above −60 dBFS |
| Trap (`unreachable`, OOB, div by zero) | that instance bypassed; rest of graph renders; engine stays up; fault flag visible; recovers on reset |
| Infinite loop / budget exhaustion | aborted within 1.2x configured budget; silent output for the block; 1000 repeats, no leak |
| Nonfinite output (NaN, inf, denormal flood) | sanitised to 0 (reuse the `compile.rs:2287` guard); counter exposed |
| Version mismatch (ABI, module version, bad meta, over-cap memory/instances) | rejected on the control thread with a message; patch opens with a bypass placeholder; never reaches audio |
| Load/compile time | ≤ 200 ms per module, control thread only |

A missed threshold names the row, the measured value and the specific alternative.

## 7. Example modules (D10 panel metadata)

1. **`demo.logic` (control-rate logic):** `Global`, scalar signals only. Inputs `a`, `b` (Cv), `gate` (Gate). Params `mode` (selector: min/max/AND/XOR/threshold), `threshold`, `offset` (knobs). Outputs `out` (Cv), `trig` (Gate). One latch float of state. Proves arithmetic/branching, scalar `Signal`, selector params; panel of 1 selector, 2 knobs, 3 jacks.
2. **`demo.bitfilter` (stateful audio processor):** `Voice`, stereo. Inputs `in` (Audio, width 2), `cutoff_cv` (Cv). Params `cutoff` (Hz, log, 5 ms smoothing), `resonance`, `drive` (`advanced=[drive]`). Output `out` (Audio, width 2). State: two biquad sections per channel plus denormal guard, saved as versioned bytes. Proves block loops, smoothing, voice reset, state across swaps; build variants (`trap`, `spin`, `nan`) drive the fault tests.

Both ship a `Panel` (Knob/Selector/Jack placements, light/dark PNG ≤128 KiB) validated by `Panel::validate`, and an exposure list so the D09/D10 UI shows them with no code-module special case. A Faust variant of example 2 is optional.

## 8. PR breakdown (in order)

| # | PR | Size | Content |
|---|---|---|---|
| 1 | Dynamic module metadata + code-module seam | M (~400 LOC) | owned `ModuleInfo`, dynamic registry lookup, `CodeModule` shell with a fake backend, fault flag + bypass + nonfinite guard, allocation-count test |
| 2 | `Backend` trait + native reference + both examples in Rust | M (~500) | prepare/reset/process/save/load trait, native impl, bench harness skeleton |
| 3 | wasmtime backend (feature `code-wasmtime`) | M (~450) | loader, ABI checks, fuel and epoch, io copy, trap handling, fault tests, examples built to wasm from a `no_std` crate |
| 4 | wasmi backend (feature `code-wasmi`) | S (~250) | same trait, same fault suite |
| 5 | Measurement run + report | S (~150 + data) | raw CSV, thresholds table, recommendation, pinned versions |
| 6 | Panel metadata + UI | S-M (~300) | `kabl_meta` → exposures/panel, D10 reuse, missing-version placeholder |
| 7 | Faust authoring check (optional) | S (~150) | wrap one Faust DSP, licence note |

Risks: (a) static `ModuleInfo` touches many call sites, so PR 1 may balloon; mitigate with leaked boxes and leave built-ins alone. (b) wasmtime needs a newer rustc than the pinned toolchain and a large tree. (c) Cranelift needs executable memory, which may fail in hardened or plug-in hosts (REAPER/CLAP). (d) Fuel is instruction-based, not time-based. (e) Embedding `.wasm` in `.kabl` is a format change; D11 uses a sidecar. (f) io copying may dominate tiny modules. (g) The spike kernel is tiny; real DSP may shift ratios.

## 9. Dependencies, licences, size

- `cargo deny check licenses` with the repo `deny.toml` was run on the spike's full tree (wasmtime 45.0.3 + cranelift, wasmi 2.0.0, wat): **every dependency passes** (Apache-2.0 WITH LLVM-exception, MIT, Apache-2.0 etc. are all on the allow list); the only failure is the spike crate itself being unlicensed. `bans` and `advisories` are not yet run; do that in PR 3.
- Size: the unstripped spike binary with both runtimes and the text parser is 17.9 MB. The real per-runtime cost in the standalone/CLAP build is measured in PR 3/4 (stripped, with and without the feature). Pass: wasmtime ≤ +12 MB or kept behind a cargo feature; wasmi ≤ +2 MB.
- MSRV: local rustc 1.93 only resolves wasmtime 45; pin the exact version in `Cargo.lock` and record the rustc floor.
- Faust: compiler is GPL with a library exception; generated-output licensing to be confirmed before D12.

## 10. Open questions for Kosta (recommended default)

1. Primary runtime? **Build both behind the `Backend` trait, decide from PR 5 data; expect wasmtime primary, wasmi as the no-JIT fallback.**
2. Is a JIT acceptable in plug-in builds (CLAP/REAPER)? **Allowed in standalone; test CLAP in REAPER during PR 5 before deciding.**
3. Voice model? **One instance per voice (simple, isolated); revisit if instance count dominates.**
4. Fault policy? **Bypass until the user resets or reloads, with a visible fault indicator; no auto-retry.**
5. Where does the `.wasm` live? **Sidecar file in D11; embedding in `.kabl` is a D12 format decision.**
6. Budget per block? **Fuel as hard stop at about 25 % of the block budget, plus wall-clock checks in tests.**
7. Faust example in D11? **Optional PR 7, cut first.**
8. State across versions? **Matching version restores state; a different version starts fresh and reports it.**
