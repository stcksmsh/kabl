# Interaction and material repair

## Final interaction adjustment

More now measures available height from the viewport rather than the modal's previous size. Its top-left origin stays stable; one capped scroll body contains the native face and exact-entry section, with Close above it. Authored Public controls shares the viewport/position policy.

Owned scroll regions consume leftover smooth wheel delta at boundaries using exact allocated, clipped, topmost bounds. The rack reads remaining input after children and menus. Modifier zoom is available on uncovered rack, while an inner scroll region owns wheel gestures under its pointer. Keyboard and original native control code remain intact.

Insertion is a presentation layer after stationary panels/cables/badges and before the lifted ghost. Both the preview and drop still use the existing drop plan, so this correction changes visibility rather than accepted drag geometry or packing semantics.

The rack uses one visible scene containing native modules and direct child composite faces. Root excludes owned leaves; a subpatch shows only its direct members and direct child faces. Composite movement updates its own position and leaves all stored leaf positions untouched. The existing editor and flat synthesis graph remain the source of sound and chronological history.

Each item body shares selection and drag ownership. Controls, jacks and buttons register their own gestures; the default card title disables selectable text so title drag reaches the item. A drag records the original displayed rectangle, width and exact pointer offset. The document stays unchanged while a disabled foreground copy follows the pointer freely, with reduced opacity and a small shadow. The original scene leaves a faint placeholder. A legal preview inserts at neighbour centres, retaining gaps where possible and shifting only the destination row when needed. Drop writes the resolved positions as one Group; Escape suppresses the drop. Stored horizontal positions and scene coordinates use the same rule, avoiding the six-point preview/drop drift found in independent review. Edge scrolling moves only the camera and the new-row destination appears only during dragging.

Entering internals snapshots scope, camera, selection, inspection, routing and reveal bookkeeping. Breadcrumb names follow the existing parent tree. First entry fits the saved contents; Back restores the exact saved view instead of re-triggering inspection pan or deeper navigation. Exposed boundary buttons bind the existing ports. Outside clocks and cues are described by identity, including outside cues that launch internal sequencers; outside modules are not duplicated. Add appends after all visible item widths and adds directly to the current instance as one chronological edit. Parameter and port reveal enter a nested leaf's direct owning scope.

More controls uses egui's existing Modal with a blocking backdrop. It draws the original native knobs, selectors and jacks together with the advanced area in a scrollable focused view; the underlying native face remains a noninteractive placeholder. Original parameter IDs, routing widgets and cables are retained. Tall or wide advanced regions scroll within the viewport. The keyboard/exact value section reuses standard parameter editors, including advanced values, without another control model. Closing by Escape, button or backdrop consumes the modal gesture. Camera/reveal/pan handlers respect the modal, so opening or closing cannot restructure the outer rack. The authored face's public fallback also uses a modal. More controls, Inspect internals and Edit face remain separate operations.

Native Edit face reuses face.* presentation metadata. Visibility differs from defaults only when needed; order stores changed ranks under face.order.<canonical parameter>. Sequencer banks share canonical slot choices and order. Existing same-kind knob or selector slots are reassigned without changing native jack positions or parameter identity. Reorder applies within knob/selector rows rather than promising arbitrary cross-kind geometry. Apply is one Undo transaction; Restore defaults resets the draft before Apply. Saved parameter-count limits are checked before committing extra metadata. Hidden controls remain in More. Pins, labels, routes, controllers, embedded definitions and host lane identities are untouched.

Light visuals now use warm pale chrome and rack surfaces with dark text across drawers, menus, windows and dialogs. Dark visuals use charcoal chrome and more readable muted sectional faces. Both themes use the same geometry, assets and interaction paths. Selection backgrounds deliberately contrast with shared text. Existing V3 satin grain, recessed hardware and continuous section colour remain; existing embedded project artwork is preserved. No new reference or generated bitmap is shipped.

This repair does not expand rack height semantics, synthesis, controller architecture, package formats or D09 identity rules. UI transitions and asset/layout work stay on the control thread. D08 callback contracts and pending performance/hardware limits remain unchanged.
