kabl directions

Eight combinations of app material and face style (recommended defaults: Signal solid for dark, Drafting solid for light), drawn as the whole app: rack with routing drawer, Perform, Sounds browser. Same patch everywhere. 1440×900 is standalone; 1180×680 is the plugin window, where the rack drops to the compact zoom tier from R1. Every shape is egui-drawable.

What stays the same in all six

One toolbar, one drawer, one status bar, one icon set. Colour only for signals (audio, CV, gate, pitch), live state, and one accent. Module family is a 3 px stripe or the title colour, never the whole face. Depth only on knobs, jacks and displays.

How to judge

Look at the plugin size first: it is the harder case. Then flip Rack ↔ Perform: a direction works only if both feel like the same product.

Placeholders

Acid Line, Slab City and Rope Walk are real factory sounds. Other sound names, macro names and scene names are invented for layout.
