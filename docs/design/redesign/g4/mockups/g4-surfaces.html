G4 decisions

Q1 · frames

Three frame kinds, one family

Modal (blocks, scrim, title 17/600, footer actions right, primary last; widths 400 / 520 / 760). Tool window (non-blocking, 44 px title bar with drag grip, used only for advanced tools). Popover (menus, dropdowns, tooltips; no scrim). All: radius 12 (menus 10), 3-step stacked shadow, close button 28 px top-right, Esc closes.

Q2 · editors

One drawer editor kit

Header (title + kind chip + Explain link), condensed section labels, rows of label / control / mono value. Seq, cable pattern and Perform share one step-grid widget (bars, playhead outline, tap = on/off, drag = value). Cues are cards with drag handles and playing/queued chips.

Q3 · wavetable

Bottom dock, not a floating window

Full rack width, 330 px (280 at 1180). Rack stays visible above; drawer stays usable. The same dock hosts future large editors. A floating window at 1180×680 covers the face being edited.

Q4 · developer tools

Same kit, marked ADVANCED

Composites, panel authoring and edit face use the kit frame, fields and buttons with an ADVANCED tag; no bespoke layout. Fix the 1180 clipping by left-anchoring at 40 px. Edit face merges into More controls as a second tab (Controls / Face layout).

Q5 · empty and error

One pattern each

Empty: icon in a circle, title, one line, up to two actions. Errors: toast top-right of the rack (severity bar + icon + title + mono detail + actions); errors stay until dismissed, warnings 8 s, success 3 s; status bar shows a red count while any error is open. Inline form errors are a banner inside the dialog, not a red line.

Q6 · file browser

Style the built-in one

Needed in plugin hosts and keeps one look. Back / up / home, breadcrumb, filter, places sidebar (Home, Patches, Sounds, Recent), folder and file icons, Name + Modified columns, empty-folder state. Native OS dialogs: possible later for standalone, not in 1.0.

Q7 · scrims and shadows

Warm dark scrim on both

Graphite: scrim black 55 %, shadow black. Paper: scrim #1A1917 at 28 % (never white), shadow at 18 %. Shadows are three stacked alpha rects (no blur). Paper surfaces also keep their 1 px line border.

Drawer at 1180

Overlay, never pushes the rack

≥ 1280 px: docks at 320 px. Below: 44 px rail; panels open as a 320 px overlay with shadow over the rack. Fixes "drawer covers faces" without shrinking the rack zoom.

Accent on paper

Fills orange, small text darker orange

Fills, arcs, toggles: #F2A33A in both themes (ink #1C1206, 8.9:1). Accent text on paper: #A94F00 (4.6:1 on bg, 5.3:1 on surface). States: bad #F06A5F / #C2362B, good #5CCB8A / #2E7D4F, warn #E3A93C / #9A6200, all ≥ 4.5:1 on their surface.
