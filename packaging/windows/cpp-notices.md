## C++ libraries in the Windows VST3

Fetched by CMake in `packaging/windows/vst3` at pinned tags, outside `Cargo.lock`, and kept by hand in `packaging/windows/cpp-notices.md`. They are linked into `kabl.vst3` only.

- clap-wrapper v0.18.0 (free-audio/clap-wrapper): MIT
- {fmt} 11.1.4, vendored in clap-wrapper `libs/fmt`: MIT with the {fmt} binary exception
- PreSonus plugin extensions, vendored in clap-wrapper `libs/psl`: public domain
- VST 3 SDK v3.8.0_build_66 (steinbergmedia/vst3sdk): MIT
- CLAP SDK 1.2.10 (free-audio/clap): MIT

VST is a registered trademark of Steinberg Media Technologies GmbH.
