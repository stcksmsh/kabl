# kabl logo

The artwork is Kosta's. `kabl-logo-source.png` is his original (1254x1254, black on off-white,
no alpha).

The two masks are derived from it by `levels` on the luminance (no redrawing): white RGB with the
ink coverage as alpha, so the UI can tint them from the theme and one asset serves light and dark.

- `kabl-lockup-mask.png`: the full lockup (cable loop, plugs and wordmark), 768x768.
- `kabl-wordmark-mask.png`: the lowercase "kabl" alone, 480 px wide.

A vector trace would be sharper at very large sizes; no tracing tool was available.
